# PromptLab AI – Prompt Engineering Experimentation

## Overview

PromptLab AI is a web-based application developed using Python and Streamlit to understand and experiment with different prompt engineering techniques. It allows users to observe how different prompting methods influence AI-generated responses.

The application uses the Groq API to generate responses from a large language model.

## Project Objective

To understand and experiment with different prompt engineering techniques and learn how they influence AI-generated responses.

## Features

* **Zero-Shot Prompting:** Generates responses without providing examples.
* **Few-Shot Prompting:** Uses examples to guide the AI's response.
* **Role-Based Prompting:** Assigns a specific role to the AI to produce suitable responses.
* **Structured Prompting:** Organizes responses into predefined sections.
* **Step-by-Step Prompting:** Encourages clear, sequential explanations.
* **Generate Response:** Generates an AI response using the selected technique.
* **Compare All Techniques:** Compares responses generated using all five prompting techniques.

## Installation and Setup

### 1. Install Dependencies

```bash
py -m pip install -r requirements.txt
```

### 2. Configure the Groq API Key

Create an API key through the Groq developer platform.

Set the API key in PowerShell:

```powershell
$env:GROQ_API_KEY="your_groq_api_key"
```

Replace the placeholder with your own API key. Do not upload or share your API key publicly.

### 3. Run the Application

```bash
py -m streamlit run prompt.py
```

The application will open in your browser.

## How to Use

1. Open PromptLab AI.
2. Enter a prompt in the input area.
3. Select a prompt engineering technique.
4. Click **Generate Response** to view the output.
5. Click **Compare All Techniques** to compare the outputs of all five techniques.

## Expected Outcome

The application demonstrates how different prompt engineering techniques can affect the structure, clarity, and style of AI-generated responses.
